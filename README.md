# Intellex

An educational chatbot that helps students understand difficult topics, one subject at a time.

## Description

Intellex is an AI-powered assistant built to support students who are struggling with a particular subject or topic. It introduces itself, learns the student's name, asks which subject they're having trouble with, and finds out exactly which topic they'd like explained. It then gives a clear, detailed explanation, and can also provide worked examples or exercises when the student wants extra practice.

## How it works

1. Intellex introduces itself and explains what it does.
2. It asks for the student's name.
3. It asks which subject the student is having issues with.
4. It asks which specific topic the student wants explained.
5. It gives a structured explanation of that topic, broken into clear sections.
6. On request, it can provide examples to work through or exercises to practice with.
